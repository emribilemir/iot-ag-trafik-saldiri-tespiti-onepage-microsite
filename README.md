# IoT Ağ Trafiği Saldırı Tespiti - OnePage Microsite

Bu repo, IoT ağ trafiğinde yapay zekâ tabanlı saldırı tespiti projesinin OnePage microsite sürümüdür.

Slide deck sürümü bu repo'ya dahil değildir. Bu repo yalnızca scroll tabanlı tek sayfa microsite deneyimi için hazırlanmıştır.

## Çalıştırma

```bash
python3 -m http.server 8766
```

Ardından:

```text
http://127.0.0.1:8766/
```

## İçerik

- `index.html`: OnePage microsite.
